附件数量是「终端告诉平台这次有几个附件」；平台 9208 里的文件总数可以不同。粤标附件 ≥3 个时拆成「N-2 张图片 + 1 段视频 + 1 个车辆状态数据记录文件（bin）」，平台的媒体列表一般只展示图片和视频，bin 不显示。实际上传了哪些文件看日志里的「[附件] 9208 要求 …」一行。

外设状态与信息

0900 透传 F7 / F8

平台 8900（类型 0xF7/0xF8 + 外设 ID 列表）查询时自动以 0900 应答；外设 ID 列表为空时上报全部外设。工作状态为“断开连接”的外设升级时回“未找到目标设备”。

异常信息与升级模拟

0xF1/0xF2 为厂家自定义 DWORD（可输入 0x 开头十六进制），非 0 时附带在每条 0200 中。8105 命令字 1 按升级文件名 设备类型_厂家编号_设备型号_依赖版本_软件版本.后缀 判断升级对象（01 终端 03 ADAS 04 DSM 05 BSD 06 TPMS），逐步上报 0x1FC4 升级进度，最后 0108 升级结果。

场景库

编辑

动作与触发条件

触发：at 开始后第 N 秒 · after 上一步完成后 N 秒 · atPoint 到达轨迹第 N 点 · atProgress 轨迹进度 0~1；都不写则紧接上一步。步骤按书写顺序执行。

断言：expectDown(msgId, within, since, count, bodyPrefix) / expectState(path, op, value, within) / expectBit(kind, bit, on, within)；失败计为该步失败，命令行 jt808sim-cli -scenario 文件 按结果返回退出码。

动作：connect / disconnect / reconnect(wait) / waitOnline(timeout) / wait(seconds) / alarm(bit[,on]) / clearAlarm(bit) / clearAlarms / status(bit,on) / videoAlarm / signal / io / speed(speed) / motion(mode,speed) / position(lng,lat) / report / send(msgId,params) / raw(line) / adas(kind,alarmType,level) / replay(mult,seek,loop) / log(text) / logout，以及页面动作名（setParam、setReply 等）。bit 可写位号或名称（如 超速报警）。
