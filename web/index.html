外设状态与信息

0900 透传 F7 / F8

平台 8900（类型 0xF7/0xF8 + 外设 ID 列表）查询时自动以 0900 应答；外设 ID 列表为空时上报全部外设。工作状态为“断开连接”的外设升级时回“未找到目标设备”。

异常信息与升级模拟

0xF1/0xF2 为厂家自定义 DWORD（可输入 0x 开头十六进制），非 0 时附带在每条 0200 中。8105 命令字 1 按升级文件名 设备类型_厂家编号_设备型号_依赖版本_软件版本.后缀 判断升级对象（01 终端 03 ADAS 04 DSM 05 BSD 06 TPMS），逐步上报 0x1FC4 升级进度，最后 0108 升级结果。
